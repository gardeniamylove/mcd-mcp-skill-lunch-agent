# 肾友低磷配餐 Agent · 麦当劳 MCP 智能体 Skill

> 参赛作品：麦当劳 × 腾讯 WorkBuddy 1024 MCP 智能体 Skill 黑客松

**一句话简介**：为需要控制磷摄入的人群（慢性肾病患者等低磷饮食人群）打造的麦当劳智能配餐助手——说一句话，就能在预算内筛出低磷友好的餐品组合，并自动标出高磷"避雷"项。

---

## 一、项目背景与痛点

我国慢性肾病（CKD）患者超过 1 亿人，其中相当一部分需要严格执行**低磷饮食**。但现实中：

- **外出就餐是盲区**：快餐营养表分散难查，普通消费者根本无从判断一份套餐的"磷负担"；
- **手动搭配门槛高**：即便查得到数据，在预算、忌口、营养多重约束下搭配一份套餐，对患者和家属都是繁琐的负担；
- **误触雷区代价大**：奶制品、加工肉制品、可乐等高磷食物，往往藏在看似普通的套餐里。

本项目用一句话对话替代"翻营养表 + 按计算器"的全过程，让低磷饮食人群也能安心吃一顿麦当劳。

## 二、功能特性

| 功能 | 说明 |
| --- | --- |
| 低磷智能筛选 | 基于餐品营养数据与营养学常识，识别高磷风险餐品（奶制品、加工肉制品、含磷酸饮料等）并自动过滤 |
| 预算约束配餐 | 调用价格核算工具，确保推荐组合严格落在用户预算内 |
| 忌口/偏好规避 | 支持"避开含奶甜品""不要牛肉"等自然语言忌口条件 |
| 时段感知 | 区分早餐/正餐时段在售餐品，不推荐当下买不到的东西 |
| 避雷清单 | 除推荐组合外，主动列出高磷高风险餐品，帮助用户建立长期认知 |
| 全程免责提示 | 每次推荐附医学免责声明，明确"仅作参考，不替代医嘱" |

## 三、使用方式

### 3.1 前置准备

1. 前往 [open.mcd.cn](https://open.mcd.cn) 申请你自己的麦当劳 MCP Token（免费）；
2. 参考本仓库的 `mcp-config.example.json`，将 Token 填入 WorkBuddy 的 MCP 配置（真实 Token 请勿提交到任何公开仓库）。

### 3.2 开始对话

在 WorkBuddy 中直接提问，例如：

```
帮我推荐 50 元以内低磷的麦当劳午餐，避开含奶甜品
```

```
早餐，30 元预算，慢性肾病饮食，能吃什么？帮我避开高磷的
```

Agent 将自动完成：**查询在售餐品 → 获取营养数据 → 低磷筛选与避雷标记 → 价格核算 → 输出推荐组合**。

## 四、工作原理

```
用户自然语言需求（预算 / 忌口 / 低磷）
        │
        ▼
┌─────────────────────────────────┐
│  query-meals                    │  查询当前时段在售餐品
│  list-nutrition-foods           │  获取餐品营养基础数据
│  （热量 / 蛋白质 / 钠 / 钙等）   │
└─────────────────────────────────┘
        │
        ▼
  低磷风险识别与过滤（高磷品类标记 + 钠/蛋白指标辅助）
        │
        ▼
┌─────────────────────────────────┐
│  query-meal-detail              │  查看套餐组成，拆分评估
│  calculate-price                │  组合价格核算，校验预算
└─────────────────────────────────┘
        │
        ▼
  推荐组合 + 避雷清单 + 医学免责声明
```

> 详细的 MCP 工具清单与调用逻辑见 [MCP_INTEGRATION.md](./MCP_INTEGRATION.md)。

## 五、技术栈

- **MCP 协议**（Model Context Protocol）：标准化对接麦当劳开放服务，服务地址 `https://mcp.mcd.cn`
- **腾讯 WorkBuddy**：无代码 Agent 搭建与运行平台
- **麦当劳开放 MCP 工具集**：营养查询、餐品查询、套餐详情、价格核算

## 十、免责声明

> **本项目所有输出仅为营养数据查询参考，不构成医疗诊断或饮食处方建议。** 麦当劳 MCP 公开数据中不包含直接磷含量检测值，本项目的低磷筛选基于公开营养指标与营养学常识推断。低磷饮食方案请务必遵从临床医生或注册营养师的专业指导。
